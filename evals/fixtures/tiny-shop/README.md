# tiny-shop（评测样本）

这是一个**刻意植入缺陷**的最小样本仓库，只用于评测 `deep-code-review` 的审查能力。
它不是生产代码，也不实现完整业务。

## 业务约定

- **所有金额一律以「分」为单位存储与比较。** 任何从「元」到「分」的换算必须使用同一个实现，
  否则同一个金额在两条路径上会算出不同的分数。
- 订单金额 `Order.Amount` 用十进制元表示，进入结算流程后统一换算为分。
- 结算流程只读订单存储：它不修改订单，也不回写数据库。

## 结构

```text
internal/
├── checkout/   结算流程
└── refund/     退款流程
```

两个包都是模块内部的（`internal/`），不构成对外公开契约。
