# rule-engine（评测样本）

这是一个**刻意植入缺陷**的最小样本仓库，只用于评测 `deep-code-review` 的审查能力。
它不是生产代码，也不实现完整业务。

## 业务约定

- 金额一律以**分**为单位。`Item.Price` 是单价，`Item.Count` 是数量。
- 促销规则 `Rule` 在购物车同时包含它列出的全部 SKU 时生效，立减 `Discount` 分。
- `Rule.Depends` 列出必须先应用的规则。**多条规则依赖同一条规则是允许的**（共享依赖）。
- 规模：一次请求的购物车最多 **200 个商品行**；规则集最多 **200 条规则**；依赖链最深 **50 层**；一条规则最多列 **12 个 SKU**。
- 两个包都在模块内部（`internal/`），不构成对外公开契约。

## 结构
